01 / About

Curious by nature.

I'm Swapnil Lohar — a developer who works across the full stack of software, from low-level C systems to browser-based interfaces and academic 3D research. I care deeply about how things actually work under the hood.

B / C Microproject

Terminal Game

A Windows console endless-runner game in C. Press Space to jump, avoid obstacles, track score and high score, and survive as the game speeds up. It uses the supplied Windows console source with conio.h and windows.h.

  • C
  • Game Loop
  • State Machine
  • Terminal I/O

What I learned: how keyboard timing, collision checks, and a simple score loop create game feel.

Bunk Tracker

A C++ classroom escape/quiz game. The supplied source and screenshots use rooms, keys, questions, inheritance, polymorphism, and an escape objective to turn OOP concepts into a playable system.

  • C++

D / CGR Microproject

Environment Simulator

A Turbo C++/BGI graphics game in which the player plants a seed, provides water, sun, fertilizer, and anti-insect treatment, then plucks fruit to win. Repeating actions makes the plant decay.

  • C
  • CGR
  • Simulation
  • Graphics

What I learned: how a small simulation turns repeated input into changing state and feedback.
